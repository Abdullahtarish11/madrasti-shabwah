# مدرستي شبوة

منصة تعليمية عربية متجاوبة تعمل كـ PWA وتدعم العمل دون اتصال، موجهة لمدارس ومراحل وكليات محافظة شبوة في اليمن.

## المميزات

- واجهة عربية بالكامل مع دعم اتجاه RTL.
- تصميم متجاوب مناسب للهواتف واللابتوب.
- قابل للتثبيت على الأجهزة المحمولة كـ PWA.
- دعم التخزين المؤقت والعمل بدون اتصال عبر Service Worker.
- قسم رئيسي للمديريات والمدارس.
- قسم المراحل الدراسية والمواد.
- قسم الكتب والمناهج مع إمكانية تنزيلها لاستخدامها دون اتصال.
- قسم الكليات والجامعات.
- محرك بحث سريع.
- لوحة إدارة مستقبلية جاهزة للتوسع.

## متطلبات التشغيل

- Node.js 18 أو أحدث
- npm أو yarn

## التشغيل محليًا

```bash
npm install
npm run dev -- --host
```

ثم افتح الرابط الظاهر في الطرفية، عادةً:

```text
http://localhost:5173
```

## بناء المشروع للإنتاج

```bash
npm run build
```

يتم إنشاء ملفات الإنتاج داخل مجلد `dist`.

## النشر

يمكن نشر المشروع على أي خدمة تستضيف تطبيقات Vite مثل:

- Vercel
- Netlify
- GitHub Pages
- أي خادم ثابت يدعم HTML/CSS/JS

## ملاحظات مهمة

- تم تصميم بيانات التطبيق لتكون تجريبية وواضحة فقط، بدون استخدام أسماء مدارس أو كتب حقيقية.
- لا يتم تضمين كتب محمية بحقوق النشر داخل المشروع.
- يمكن لاحقًا ربط النظام بنظام استيراد ملفات مرخصة أو إعلانات للمستخدم لإضافة المحتوى المسموح.
- تم تجهيز إمكانية تنزيل الكتب على الهاتف لتخزينها محليًا والعمل بدون اتصال.

## التطوير المستقبلي

- ربط قاعدة بيانات حقيقية.
- دعم إدارة محتوى عبر لوحة تحكم.
- إضافة نظام مستخدمين للمعلمين والطلاب.
- رفع ملفات PDF مباشرة مع تخزينها محليًا أو في خدمة سحابية.
- تنويع أنواع المحتوى مثل الفيديوهات والملفات الصوتية.
