# مدرستي شبوة

نسخة أولية عربية متجاوبة (RTL) لتصفح المحتوى التعليمي المجتمعي في محافظة شبوة. هذه الواجهة لا تتصل بخادم ولا تدّعي توثيق مدارس أو كتب أو برامج؛ يبدأ سجل المدارس والكتب فارغًا، وتُعرض البيانات التي يضيفها المستخدم على جهازه فقط.

## المتطلبات

- Node.js 18 أو أحدث
- npm

## التشغيل والتطوير

```bash
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية (عادةً `http://localhost:5173`). يتاح Service Worker على localhost أو عبر HTTPS. لتجربة وضع عدم الاتصال، افتح التطبيق مرة على الأقل، ثم استخدم أدوات المطور > Network > Offline وأعد تحميل الصفحة.

## بناء الإنتاج

```bash
npm run build
npm run preview
```

ملفات النشر في `dist/`. انشر محتويات المجلد على استضافة ثابتة تدعم HTTPS، واضبط مسار الاستضافة الفرعية إن لزم. يتطلب تثبيت PWA وService Worker سياقًا آمنًا (HTTPS، أو localhost للتطوير).

## الميزات الموجودة

- أقسام الرئيسية، المديريات، المدارس، المراحل والمواد، الكتب، التعليم العالي، البحث، وإدارة المحتوى.
- بحث فوري ضمن المديريات والسجلات الموجودة محليًا.
- إضافة سجلات مدارس ومؤسسات على الجهاز عبر نموذج الإدارة، وحذفها.
- إضافة ملفات PDF يختارها المستخدم، وقراءتها، وحفظ نسخة فعلية في IndexedDB للاستخدام دون اتصال.
- حفظ البيانات الوصفية محليًا في `localStorage`، وإظهار مطالبة تثبيت التطبيق عندما يدعمها المتصفح.
- Service Worker يخزن غلاف التطبيق والملفات المحلية من نفس المصدر.

## حدود النسخة الأولية

- لوحة الإدارة محلية فقط، بلا حسابات أو صلاحيات أو مزامنة أو API. المحتوى المضاف على جهاز لا يظهر على جهاز آخر.
- ملفات PDF لا تُضمّن في المستودع ولا تُرفع إلى خادم. المستخدم مسؤول عن الحصول على الإذن اللازم قبل استيرادها. حذف سجل الكتاب يحذف النسخة المحلية المرتبطة به من IndexedDB.
- المدارس فارغة عمدًا لتجنّب اختلاق بيانات. قائمة المديريات خيارات أولية يجب تدقيق تهجئتها وتقسيمها إداريًا قبل النشر الرسمي. سجل جامعة شبوة معروض كبيان أولي غير متحقق؛ تحقّق من الاسم والموقع والبرامج قبل الاعتماد. لا تمثل المراحل والمواد توثيقًا رسميًا لمنهج.
- التثبيت يعتمد دعم المتصفح، ويجب إضافة أيقونات PNG بمقاسات موصى بها عند إعداد إطلاق إنتاجي كامل.
- التخزين المحلي محدود بسعة المتصفح ويمكن مسحه من إعدادات الجهاز. وفّر مساحة قبل تنزيل ملفات كبيرة.

## البنية

```text
src/App.jsx                 واجهة الأقسام وإدارة المحتوى محليًا
src/data.js                 تصنيفات أولية بلا أسماء مدارس أو كتب تجريبية مزيفة
src/storage.js              تخزين ملفات PDF في IndexedDB
src/styles.css              تصميم RTL متجاوب
public/manifest.webmanifest بيانات PWA
public/sw.js                Service Worker للتخزين المؤقت
```

## الاختبار

```bash
npm run build
```

ثم جرّب: إضافة PDF، حفظه على الجهاز، فتحه بعد قطع الاتصال؛ إضافة مدرسة والبحث عنها؛ إضافة مؤسسة وحذفها؛ وتثبيت التطبيق على هاتف Android عبر HTTPS. لا توجد اختبارات آلية مهيأة بعد.
